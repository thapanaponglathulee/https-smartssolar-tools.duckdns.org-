## ขอบเขต — อ่านก่อนลงมือ

ระบบมีหน้า Dashboard **สองหน้า** ชื่อเหมือนกัน คนละโมดูล เอกสารนี้พูดถึง **บุคคล › Dashboard** เท่านั้น

| สิ่งที่อยู่บนหน้าจอ | เจ้าของ | อยู่ในงานนี้ |
|---|---|---|
| การ์ดวันนี้ · รายชื่อยังไม่เช็คอิน · สรุปรายเดือน · รายงานมาสาย · บรรทัดใบเซอร์ | บุคคล | ✅ แก้ได้เต็มที่ |
| บรรทัดสอบเทียบเครื่องมือในกล่องแจ้งเตือน | เครื่องมือ | ⚠️ แตะแค่การแยกกล่อง |
| การ์ด "ของที่ยืมอยู่" ในหน้าบุคคล | เครื่องมือ | ⚠️ แค่ตัดสินว่าวางตรงไหน |
| เครื่องมือ 164 ชิ้น · ยืมคืน · Renew · แผนจอง | เครื่องมือ | ❌ ไม่แตะเลย |

**กติกาข้อเดียวเวลาไม่แน่ใจ** — งานฝั่งบุคคลแก้ได้ว่า *ข้อมูลของเครื่องมือจะไปแสดงตรงไหน* แต่ห้ามแก้ว่า *ข้อมูลนั้นคำนวณมาอย่างไร*

## รายการงาน

### ด่วน — ทำก่อนรอบพัฒนาปกติ

**DSH-01 หยุดใช้ตัวเลขค่าข้าวชุดปัจจุบัน**
- ขึ้นแถบเตือนบนตารางสรุปรายเดือนว่ายอดอยู่ระหว่างตรวจสอบ ห้ามใช้จ่ายจริง
- **ปิดปุ่มดาวน์โหลด Excel** จนกว่าจะแก้ ALW-02 และ ALW-06 เสร็จ
- ฝ่ายบุคคลไล่ตรวจย้อนหลังว่ามีรอบไหนจ่ายตามยอดนี้ไปแล้ว

> ตัวเลขผิดที่ยังอยู่บนหน้าจอ อันตรายกว่าตัวเลขที่หายไป เพราะคนจะเชื่อว่ามันถูก

**DSH-02 ตรวจและแก้เกณฑ์เวลามาสาย**
ตรวจสามอย่าง — เกณฑ์เป็น 08:30 หรือยัง · มีช่วงผ่อนผันกี่นาที · ยกเว้นกะกลางคืน คนที่ได้รับยกเว้นเช็คอิน และวันหยุดตามปฏิทินแล้วหรือยัง
เกณฑ์ต้องเป็นค่าตั้งค่า และเมื่อแก้แล้ว **ต้องคำนวณย้อนหลังใหม่ทั้งหมด**
*ตรวจรับ* คนเข้างาน 08:29 ต้องไม่สาย และจำนวนครั้งที่สายของเดือน ส.ค. ต้องเปลี่ยนอย่างมีนัยสำคัญ ถ้าไม่เปลี่ยนเลยแปลว่ายังไม่ได้แก้จริง

**DSH-03 ตัดบัญชีทดสอบออกจากทุกตัวเลข**
เพิ่มสถานะบัญชีทดสอบ แล้วกันออกจากการนับทุกที่ · **ห้ามลบบัญชี** ให้ทำเครื่องหมาย · ตรวจว่ามีบัญชีอื่นที่ไม่ใช่พนักงานจริงอีกไหม

**DSH-04 สิทธิ์การมองเห็นและการดาวน์โหลด**
ตารางสรุปรายเดือนแสดงค่าข้าวรายคนทั้งบริษัท + ดาวน์โหลดได้ → **ขัด CI-03**
- ตรวจก่อนว่าพนักงานทั่วไปเห็นไหม ถ้าเห็นให้ปิดทันที
- พนักงานเห็นเฉพาะของตัวเอง · หัวหน้าเห็นลูกทีม · HR และผู้บริหารเห็นทั้งหมด
- ปุ่มดาวน์โหลดจำกัดตามสิทธิ์เดียวกัน + บันทึกว่าใครดาวน์โหลดเมื่อไหร่
- **ตรวจที่ payload หลังบ้านด้วย ไม่ใช่แค่ซ่อนใน UI**

### รอบ 1

**DSH-05 แยกกล่องแจ้งเตือน ใบเซอร์ ออกจาก สอบเทียบเครื่องมือ**
- แยกเป็นสองกล่อง แล้วในแต่ละกล่องแยกอีกชั้นระหว่าง **เกินกำหนดแล้ว** กับ **ใกล้ครบกำหนด**
- กล่องใบเซอร์เรียงตาม **วันสุดท้ายที่ยังต่อทัน** ไม่ใช่วันหมดอายุ (บางใบต้องยื่นล่วงหน้า 30 วัน และขาดแล้วต้องประเมินใหม่)
- กล่องสอบเทียบ **คงตรรกะเดิมทุกอย่าง** งานนี้แตะแค่การแบ่งกล่องและการจัดวาง

*ตรวจรับ* เห็นใบเซอร์ที่เกินกำหนดโดยไม่ต้องเลื่อนผ่านรายการเครื่องมือแม้แต่บรรทัดเดียว และตัวเลขในกล่องสอบเทียบเท่าเดิมทุกรายการ

**DSH-06 การ์ดวันนี้ ต้องบอกขอบเขต และแตกตามสถานะรายวัน**

ปัญหาสองชั้น — ขอบเขตปนกัน (การ์ด 3 ใบแรกเป็นของบริษัท ใบที่ 4 เป็นของคนล็อกอิน) และสถานะมีแค่สองแบบ

แถวการ์ดที่ควรเป็น ตาม CI-14:
```
มาแล้ว 18   ลา 3   วันหยุด 0   รออนุมัติลา 1
ยกเว้นเช็คอิน 4   ขาดงาน 5   จากพนักงาน 31 คน
```
**ตัวเลขที่ต้องตามหาจริง ๆ คือ "ขาดงาน" ไม่ใช่ "ยังไม่เช็คอิน"**
*ตรวจรับ* ผลรวมทุกสถานะ = จำนวนพนักงานที่ทำงานอยู่จริงพอดี และคนที่มีใบลาอนุมัติแล้วต้องไม่อยู่ในกลุ่มขาดงาน

**DSH-07 เปลี่ยนค่าข้าวเป็นเบี้ยเลี้ยง และผูกกับรอบตัดจ่าย**
- หัวคอลัมน์ "ค่าข้าว" → "เบี้ยเลี้ยง" ตาม ALW-01
- "เดือนนี้" → "รอบนี้" (16 ถึง 15) ไม่งั้นตัวเลขบน Dashboard จะไม่มีวันตรงกับที่ HR ใช้ปิดรอบ
- ปุ่มเลื่อนเดือน → เลื่อนรอบ + แสดงช่วงวันที่ + สถานะรอบ (เปิด / ปิดและจ่ายแล้ว)

*ตรวจรับ* ยอดรวมของรอบบน Dashboard = ยอดในหน้าอนุมัติเบี้ยเลี้ยงของรอบเดียวกัน ไม่คลาดเคลื่อนแม้แต่บาทเดียว

### รอบ 2

**DSH-08 ทุกตัวเลขต้องกดเข้าไปหารายการได้**
ขาดงาน → รายชื่อพร้อมสาเหตุย่อย · รออนุมัติ → คิวในแท็บอนุมัติ · ชื่อคน → รายละเอียดรายวัน · จำนวนครั้งที่สาย → รายการวันที่สายพร้อมเวลาจริง
*ตรวจรับ* ไม่มีตัวเลขใดบนหน้านี้ที่กดแล้วไม่เกิดอะไรขึ้น

**DSH-09 Dashboard แสดงตามบทบาท**
หน้าเดียวแล้วซ่อนบล็อกที่ไม่มีสิทธิ์ ใช้ตารางสิทธิ์ชุดเดียวกับ APV-05

| บทบาท | เห็นอะไร |
|---|---|
| พนักงาน | ของฉัน — วันนี้เช็คอินหรือยัง · วันลาคงเหลือ · เบี้ยเลี้ยงรอบนี้ · ใบเซอร์ของฉันใกล้หมด |
| หัวหน้างาน | + วันนี้ลูกทีมมากี่คน ขาดใคร · รอฉันอนุมัติ · สัปดาห์หน้าใครลา |
| ฝ่ายบุคคล | ทั้งบริษัท เน้นรอบเบี้ยเลี้ยง · ใบเซอร์ใกล้หมด · คนที่ยังไม่เช็คอิน |
| ผู้บริหาร | ทั้งหมด + ต้นทุนแรงงานต่อไซต์ + รายการค้างอนุมัติเกินกำหนด |

*ตรวจรับ* พนักงานทั่วไปเปิดมาแล้ว Dashboard ต้องไม่ว่างเปล่า และต้องไม่มีตัวเลขของคนอื่นเลย

**DSH-10 ย้ายบล็อกสรุปส่วนตัวจากหน้าเช็คอินมาที่นี่**
หน้าเช็คอินมีบล็อก ลาคงเหลือ · เบี้ยเลี้ยงรอเบิก · ของที่ยืมอยู่ · มา-สายเดือนนี้ + ตารางวันลา
- บล็อกนี้ไม่มีปุ่มให้ทำอะไรเลย มีแต่ตัวเลขสะสม → เป็นเนื้อหาของ Dashboard
- การ์ด "ของที่ยืมอยู่" เป็นตัวเลขของโมดูลเครื่องมือ ยืนยันว่าบล็อกนี้เป็นสรุปส่วนตัวข้ามโมดูล ไม่ใช่ฟีเจอร์ของการเช็คอิน
- หน้าเช็คอินเหลือแค่แถบยืนยันบรรทัดเดียว "วันนี้เช็คอินแล้ว 08:24 ที่ CRR solar farm"
- **ต้องไม่มีตัวเลขเดียวกันปรากฏสองที่**

จำเป็นต่อ CI-20 ด้วย — ถ้ามีตัวเลขห้าชั้นใต้ปุ่ม การกดปุ่มเดียวจะกลายเป็นการเลื่อนหน้าจอ

**DSH-11 แผนกเป็นรายการปิด**
รวม `Project Manager` กับ `Project Management` · แก้ `Opeartion` → `Operation` · เติมแผนกที่ว่าง · **แยกช่องตำแหน่งออกจากช่องแผนก** (Project Manager เป็นตำแหน่ง ไม่ใช่แผนก)
ปัญหาเดียวกับ `safty` และ `ไปบ่าย-กลับเย็น` — ช่องพิมพ์อิสระที่ควรเป็นรายการปิด

**DSH-12 การ์ดรออนุมัติ ต้องผูกกับแท็บอนุมัติจริง**
ใช้ตัวเลขชุดเดียวกับคิวในแท็บอนุมัติ ไม่คำนวณแยก · แยกว่าเป็นเรื่องอะไรบ้าง · นับเฉพาะเรื่องที่คนล็อกอินมีอำนาจตัดสินตาม APV-01 · ค้างเกินกำหนดขึ้นสีเตือน

### รอบ 3

**DSH-13 มุมมองสัปดาห์หน้า ใครลาบ้าง**
ทุกอย่างบน Dashboard ตอนนี้มองย้อนหลังหรือมองแค่วันนี้ ไม่มีอะไรช่วยวางแผนล่วงหน้า ทั้งที่บริษัทรับเหมาต้องจัดคนลงไซต์ล่วงหน้า
7 วันข้างหน้า · เน้นวันที่คนลาพร้อมกันผิดปกติ · รวมใบลาที่ยังรออนุมัติแต่แยกสี · ดึงจากปฏิทินเดียวกับ CAL-01

**DSH-14 แถบเตือนเมื่อตัวเลขยังเชื่อไม่ได้**
เรื่องที่เกิดกับค่าข้าว 240 จะเกิดอีก ระบบควรบอกเองเมื่อรู้ว่าข้อมูลยังไม่พร้อม
- ไซต์ที่ยังไม่ได้ตั้งอัตรา · เช็คอินที่จับคู่รหัสไซต์ไม่ได้ · พนักงานที่ยังไม่ได้ตั้งสิทธิ์วันลา · รายการที่ยังไม่ได้เลือกประเภทการไปงาน
- ทุกแถบเตือนต้องกดไปที่รายการที่มีปัญหาได้
