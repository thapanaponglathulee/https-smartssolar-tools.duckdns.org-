## หลักการเดียวที่ต้องจำ

เบี้ยเลี้ยงกับค่าข้าวคือเงินก้อนเดียวกัน คิด **รายมื้อ ไม่ใช่รายวัน**

```
ยอดเงินของวัน = อัตราต่อมื้อของไซต์ (ณ วันนั้น) × จำนวนมื้อสุดท้าย

จำนวนมื้อสุดท้าย:
  ถ้าเป็นกะกลางคืน            → 3 มื้อ (ทับค่าอื่นทั้งหมด)
  ถ้าไม่ใช่ แต่ทำงานนอกเวลา (onsite) → จำนวนมื้อของประเภทการไปงาน + 1
  นอกนั้น                     → จำนวนมื้อของประเภทการไปงาน
```

ประเภทวัน (ปกติ / วันหยุดบริษัท / วันอาทิตย์และนักขัตฤกษ์) **เก็บไว้ในรายการแต่ยังไม่คูณเข้าเงิน** ปัจจุบันได้เท่ากันหมด

## รายการงาน

### รอบ 1 — ทำให้ตัวเลขถูกต้อง

**ALW-01 ใช้คำเดียวทั้งระบบ**
ยุบ "ค่าข้าว" กับ "เบี้ยเลี้ยง" เหลือคำเดียว ใช้ "เบี้ยเลี้ยง" ทั้งเมนู รายงาน และหัวคอลัมน์
*ตรวจรับ* ค้นคำว่า ค่าข้าว ทั้งระบบแล้วไม่พบในชื่อเมนู รายงาน หรือหัวคอลัมน์

**ALW-02 ตารางอัตราต่อมื้อรายไซต์ พร้อมวันเริ่มใช้**
เก็บเป็นประวัติ หนึ่งแถว = ไซต์ + อัตรา + วันเริ่มใช้ + วันสิ้นสุด (ว่าง = ยังมีผล)
- ขึ้นอัตรา = เพิ่มแถวใหม่ ระบบปิดวันสิ้นสุดของแถวเดิมให้เอง
- ตั้งอัตราล่วงหน้าได้
- ห้ามช่วงวันคาบเกี่ยวกันในไซต์เดียวกัน ต้องเตือนตอนบันทึก
- ไซต์ที่ไม่มีอัตราต้องเตือน ห้ามคิดเป็น 0 เงียบ ๆ
- มีอัตราเริ่มต้นของบริษัท ใช้เมื่อไซต์ยังไม่ตั้งค่า แต่ต้องแสดงว่ากำลังใช้ค่าเริ่มต้น

*ตรวจรับ* บันทึกอัตราใหม่ของ MVP ให้เริ่มเดือนหน้า → รายงานเดือนนี้ต้องเป็นอัตราเดิม รายงานเดือนหน้าเป็นอัตราใหม่

**ALW-03 ล็อกอัตราไว้กับรายการที่คำนวณแล้ว**
บันทึกอัตราที่ใช้ จำนวนมื้อ และ id ของแถวอัตรา ลงในรายการ ห้ามดึงสดตอนเปิดรายงาน
*ตรวจรับ* แก้อัตราย้อนหลัง → ยอดของรายการเดิมต้องไม่เปลี่ยน และมี audit log

**ALW-04 ตารางประเภทการไปงานและจำนวนมื้อ**
หน้าตั้งค่าที่แอดมินแก้ได้ เป็นรายการปิด หน้าเช็คอินดึงไปแสดงเป็นดรอปดาวน์
- รวม "ไปบ่าย-เย็นกลับ" กับ "ไปบ่าย-กลับเย็น" เหลือชื่อเดียว
- แยก 0 ออกจาก "ยังไม่ได้กำหนด"
- เลิกใช้ = ปิดการใช้งาน ห้ามลบ

**ALW-05 เพิ่มช่องประเภทการไปงานในหน้าเช็คอิน**
พนักงานเลือกเอง จำค่าล่าสุดเป็นค่าตั้งต้น (เหมือน CI-11) ห้ามแสดงจำนวนมื้อหรือเงินข้างตัวเลือก

**ALW-06 เครื่องคำนวณเบี้ยเลี้ยงรายวัน**
สร้างรายการอัตโนมัติทุกครั้งที่มีเช็คอินสมบูรณ์ ตามสูตรด้านบน
*ตรวจรับ*
- MVP + ประจำไซต์ = 225
- HYS + ไปเช้าเย็นกลับ = 40
- HYS + ประจำไซต์ + นอกเวลา = 160
- HYS + กะกลางคืน = 120

**ALW-07 ปิดช่องระยะ KM และลบค่ากลาง 240 บาท/วัน**
เก็บข้อมูลเดิมไว้ ห้ามลบ แต่ต้องไม่มีเส้นทางไหนที่ระยะทางเปลี่ยนยอดเงินได้

### รอบ 2 — เปลี่ยนวิธีทำงาน

**ALW-08 เปลี่ยนจากฟอร์มขอเบิก เป็นหน้าสรุปให้ยืนยัน**
แสดงรายการทั้งรอบที่ระบบคำนวณไว้ → พนักงานกดยืนยันทีเดียว วันที่มีปัญหาขึ้นเตือนพร้อมเหตุผล ทักท้วงรายวันได้แต่แก้ตัวเลขเองไม่ได้
*ตรวจรับ* พนักงานที่ออกไซต์ครบรอบส่งยืนยันได้โดยไม่ต้องพิมพ์อะไรเลย

**ALW-09 ล็อกช่องจำนวนเงิน + เส้นทางขอปรับยอด**
เงินมาจากการคำนวณเท่านั้น การปรับต้องมีเหตุผล ผู้อนุมัติ และเก็บทั้งยอดคำนวณและยอดที่ปรับ สิทธิ์เฉพาะแอดมินและผู้บริหาร

**ALW-10 กติกากันรายการผิด**
- หนึ่งวันหนึ่งคน มีรายการเดียว วันที่เช็คอินหลายไซต์ต้องมีกติกาเลือกและบันทึกเหตุผล
- วันที่ลาอนุมัติแล้ว → ไม่เกิดรายการ ถ้ามีเช็คอินค้างให้ขึ้นเป็นรายการต้องตรวจสอบ
- วันที่ลารออนุมัติ → พักไว้ ยังไม่นับเข้ายอดรวม
- วันที่ไม่มีเช็คอิน → ไม่เกิดรายการ ให้ไปแก้ที่ CI-06
- ประเภทที่ได้ 0 มื้อ → สร้างรายการยอด 0 ไม่ใช่ไม่สร้าง

**ALW-11 สถานะรายการ 6 สถานะ**

| สถานะ | นับเข้ายอดจ่าย |
|---|---|
| ระบบคำนวณแล้ว | ยัง |
| พนักงานยืนยันแล้ว | ยัง |
| รอตรวจสอบ | ยัง |
| อนุมัติแล้ว | ใช่ |
| ไม่อนุมัติ | ไม่ (ต้องแจ้งพนักงาน) |
| จ่ายแล้ว | ใช่ และล็อก |

**ALW-12 รอบตัดจ่าย 16–15 และรายการปรับปรุงข้ามรอบ**
ปิดรอบแล้วล็อก แก้เช็คอินย้อนหลังที่กระทบรอบปิด → สร้างรายการปรับปรุงในรอบถัดไปพร้อมอ้างวันต้นทาง หลักเดียวกับปิดงวดในเมนูลา
ก่อนปิดรอบต้องแสดงรายการค้างให้เคลียร์

**ALW-13 สิทธิ์การมองเห็นตัวเลข**
- พนักงานเห็นยอดของตัวเอง
- ไม่เห็นอัตราของไซต์ที่ตัวเองไม่ได้ไป และไม่เห็นยอดคนอื่น
- หน้าเช็คอินต้องไม่มีคำว่า เบี้ยเลี้ยง อัตรา เรต (CI-03)
- หัวหน้างานเห็นลูกทีม แอดมินและผู้บริหารเห็นทั้งหมด

*ตรวจรับ* ตรวจทั้งหน้าจอและ payload ที่ส่งจากหลังบ้าน ไม่ใช่แค่ซ่อนใน UI

### รอบ 3 — ต่อยอด

**ALW-14 Offsite ID ต้องผูกกับรายการจริง** — เลือกจากรายการ หรือเอาออก ห้ามเป็นช่องพิมพ์อิสระ

**ALW-15 หน้าสรุปของพนักงาน + ใบสรุปรายรอบ** — ยอดสะสมรอบปัจจุบัน วันที่ติดปัญหา ใบสรุปพิมพ์ได้ ออกแบบเพื่อมือถือ

**ALW-16 รายงานผู้บริหารและบัญชี** — เบี้ยเลี้ยงต่อไซต์ · รายคน (ส่งออกไฟล์ได้) · รายการที่ถูกปรับด้วยมือ · เปรียบเทียบระหว่างรอบ
*ตรวจรับ* ยอดรวมจากรายงานต่อไซต์ ต้องเท่ากับจากรายงานรายคน ไม่คลาดเคลื่อน

## ยังไม่ทำในรอบนี้

- **ตัวคูณตามประเภทสถานที่ — ตัดออกแล้ว 31 ส.ค. 2569** On site · Survey · O&M · Logistic/Store เป็น 1 ทั้งหมด จึงไม่มีผลกับเงินแม้แต่บาทเดียว และสิ่งที่ตัวคูณจะทำได้ ตารางประเภทงานกับจำนวนมื้อทำได้หมดแล้วในรูปที่อ่านเข้าใจง่ายกว่า เช่น Survey ได้ 1 มื้อ อ่านรู้เรื่องกว่า Survey คูณ 1 · คอลัมน์ coefficient ในไฟล์นโยบายเดิมจึงไม่ต้องนำเข้าระบบ ตัวมันคือประเภทงานตัวเดียวกับที่แยกออกมาใน CI-15 นั่นเอง
- **ค่าเดินทางตามระยะทาง** ถ้ากลับมาใช้ ต้องเป็นรายการแยกจากค่าอาหาร
- **ประเภทวันมีผลต่อมื้อ** โครงสร้างเตรียมช่องไว้แล้ว เปิดใช้ได้โดยไม่ต้องแก้ฐานข้อมูล

- ยืนยันว่าอัตรา 40/75 บาทต่อมื้อ เป็นอัตราที่มีผลตั้งแต่วันไหน เพื่อใช้เป็นวันเริ่มใช้ของแถวแรก
