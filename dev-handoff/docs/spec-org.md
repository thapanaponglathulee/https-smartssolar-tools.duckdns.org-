# ข้อกำหนดหน้าจอ — 2. Organization & Position

จัดทำ 8 ก.ย. 2569 · สถานะ: **พร้อมให้สร้างหน้าจอในต้นแบบ**
คู่กับ `spec-account.md` (ข้อ 1) ซึ่งอยู่ในเมนูเดียวกันคือ Staff/Account

---

## อ่านก่อน

**ไฟล์นี้เป็นข้อกำหนด _หน้าตา_ ไม่ใช่ข้อกำหนดพฤติกรรมทั้งหมด** — สร้างหน้าจอก่อน แล้วใช้หน้าจอตรวจว่าข้อมูลอะไรยังคิดไม่ถึง
ข้อมูลทุกตัวในตัวอย่างเป็นของสมมติ ห้ามใส่ชื่อพนักงานจริง

**ขอบเขตของข้อนี้** — บริษัท/ฝ่าย/แผนก · ตำแหน่งงาน · Reporting Line · Manager/Supervisor · Organization Chart

---

## กติกาที่ต้องยึด

> **Reporting Line ไม่ใช่สายอนุมัติ** — ยืนยัน 8 ก.ย. 2569
> ใบลาไปหัวหน้างาน เบี้ยเลี้ยงไปฝ่ายบุคคล **ผู้อนุมัติผูกกับเรื่อง ไม่ผูกกับสายบังคับบัญชา**
> Organization Chart เป็นภาพโครงสร้างองค์กร ไม่ได้เป็นตัวตัดสินว่าใครกดอนุมัติอะไร
> ถ้าวันหนึ่งอยากให้ผังเป็นตัวกำหนดผู้อนุมัติ **ต้องเปิดเรื่องเคาะใหม่ ห้ามเปลี่ยนเงียบ ๆ**

| เรื่อง | ข้อสรุป |
|---|---|
| ตำแหน่งและแผนกเป็น **ดรอปดาวน์ที่ตั้งค่าได้** | ห้ามพิมพ์อิสระ ห้าม hardcode (ACC-06) |
| ล้างข้อมูลเก่า **ให้คนกาเอง** | 31 แถวต้องให้ฝ่ายบุคคลกาถูกทีละแถว **ห้ามแปลงอัตโนมัติ** (ACC-07) |
| ไม่ลบ ใช้ปิดการใช้งาน | ตำแหน่งหรือแผนกที่เลิกใช้ ให้ปิด ไม่ลบ เพราะข้อมูลเก่าอ้างอยู่ |

**สภาพจริงที่ต้องแก้** — ช่องตำแหน่ง**ว่างทั้ง 31 คน** · แผนกเป็นข้อความอิสระสะกดสี่แบบ (`Project-Coordination` 6 · `Project-Co.` 2 · `Project Management` 1 · `Project Manager` 13 · `Opeartion&Maintenance` สะกดผิด 3)

# หน้าจอที่ต้องสร้าง

## O1 · ตั้งค่าโครงสร้างองค์กร  `หน้าตั้งค่า ไม่ใช่หน้าใช้งานประจำวัน`

โครงสร้างมี **สามชั้น** — บริษัท → ฝ่าย → แผนก

```
┌──────────────────────────────────────────────────────────┐
│  โครงสร้างองค์กร                        [ + เพิ่มฝ่าย ]  │
├──────────────────────────────────────────────────────────┤
│  บริษัท สมาร์ท เอ็น คอนซัลแทนท์ จำกัด                     │
│                                                          │
│   ▾ ฝ่ายปฏิบัติการ                        14 คน  ⋮       │
│       • แผนกติดตั้ง                        9 คน  ⋮       │
│       • แผนกซ่อมบำรุง                      5 คน  ⋮       │
│   ▾ ฝ่ายวิศวกรรมและออกแบบ                  6 คน  ⋮       │
│       • แผนกออกแบบ                         4 คน  ⋮       │
│       • แผนกสำรวจ                          2 คน  ⋮       │
│   ▾ ฝ่ายสนับสนุน                           7 คน  ⋮       │
│       • แผนกบุคคลและธุรการ                 3 คน  ⋮       │
│       • แผนกจัดซื้อ                        2 คน  ⋮       │
│       • แผนกคลังสินค้า                     2 คน  ⋮       │
│   ▾ ฝ่ายบริหาร                             4 คน  ⋮       │
│                                                          │
│   ⚠ ยังไม่ได้จัดฝ่าย/แผนก  0 คน                         │
└──────────────────────────────────────────────────────────┘
```

- ตัวเลขคนต้องเป็นจำนวนจริงและกดเข้าไปดูรายชื่อได้
- **แถวล่างสุด "ยังไม่ได้จัดฝ่าย/แผนก" ต้องมีเสมอ** แม้เป็นศูนย์ — เป็นตัวบอกว่าล้างข้อมูลเสร็จหรือยัง
- เมนู ⋮ มี เปลี่ยนชื่อ · ย้าย · **ปิดการใช้งาน** (ไม่มีลบ)
- ปิดฝ่ายที่ยังมีคนอยู่ไม่ได้ ต้องย้ายคนออกก่อน — ขึ้นข้อความบอกว่าเหลืออีกกี่คน
- ตัวอย่างข้างบนเป็นโครงสร้างสมมติ **ของจริงต้องให้ฝ่ายบุคคลกรอกเอง**

## O2 · ตั้งค่าตำแหน่งงาน

```
┌──────────────────────────────────────────────────────────┐
│  ตำแหน่งงาน                          [ + เพิ่มตำแหน่ง ]  │
├──────────────────────────────────────────────────────────┤
│  ชื่อตำแหน่ง            ระดับ        ใช้อยู่   สถานะ     │
│  ช่างเทคนิคติดตั้ง       ปฏิบัติการ    9 คน    ใช้งาน  ⋮ │
│  ช่างเทคนิคซ่อมบำรุง     ปฏิบัติการ    5 คน    ใช้งาน  ⋮ │
│  หัวหน้าชุดติดตั้ง       หัวหน้างาน    2 คน    ใช้งาน  ⋮ │
│  วิศวกรออกแบบ           วิชาชีพ       4 คน    ใช้งาน  ⋮ │
│  เจ้าหน้าที่บุคคล        สนับสนุน      1 คน    ใช้งาน  ⋮ │
│  พนักงานขับรถ           ปฏิบัติการ    0 คน    ปิดแล้ว ⋮ │
└──────────────────────────────────────────────────────────┘
```

- ช่อง **ระดับ** ใช้จัดกลุ่มในรายงานและในผัง ไม่ได้ให้สิทธิ์อะไร
- คอลัมน์ "ใช้อยู่" กดเข้าไปดูรายชื่อได้ · ตำแหน่งที่ 0 คนปิดได้เลย
- **ตำแหน่งไม่ให้สิทธิ์** — เขียนบรรทัดนี้ไว้บนหน้าจอเลย เพราะเป็นความเข้าใจผิดที่เกิดซ้ำ สิทธิ์อยู่ที่แท็บสิทธิ์ในโปรไฟล์

## O3 · หน้าล้างข้อมูลเดิม  `ACC-07` `ใช้ครั้งเดียวแล้วเลิก`

หน้าที่ให้ฝ่ายบุคคลกาแผนกและตำแหน่งของ 31 คน **ทีละแถว**

```
┌─────────────────────────────────────────────────────────────────┐
│  จับคู่ข้อมูลเดิม                        เสร็จแล้ว 18 / 31      │
│  ▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░                                          │
├─────────────────────────────────────────────────────────────────┤
│  ชื่อ            ค่าเดิมในระบบ          ฝ่าย/แผนก    ตำแหน่ง    │
│  สมชาย ใจดี      Project-Coordination   [ เลือก ▾ ]  [ เลือก ▾ ]│
│  วิภา ตั้งมั่น    Project Manager        [ เลือก ▾ ]  [ เลือก ▾ ]│
│  ธนา ศรีสุข      Opeartion&Maintenance  [ เลือก ▾ ]  [ เลือก ▾ ]│
└─────────────────────────────────────────────────────────────────┘
```

- **ต้องแสดงค่าเดิมไว้ข้าง ๆ ตลอด** ไม่งั้นคนกาไม่รู้ว่ากำลังแปลงอะไรเป็นอะไร
- **ห้ามมีปุ่ม "จับคู่อัตโนมัติ" หรือ "เดาให้"** — `Project Manager` 13 คนอาจไม่ใช่ตำแหน่งจริงสักคน ระบบไม่มีทางรู้
- บันทึกทีละแถวได้ ปิดหน้ากลางคันแล้วกลับมาทำต่อได้
- แถบความคืบหน้าต้องเห็นชัด เพราะงานนี้ทำครั้งเดียวแต่ยาว

## O4 · Organization Chart

```
                    ┌──────────────────┐
                    │  กรรมการผู้จัดการ  │
                    └────────┬─────────┘
          ┌──────────────────┼──────────────────┐
     ┌────┴─────┐      ┌─────┴────┐      ┌──────┴─────┐
     │ ฝ่ายปฏิบัติการ│      │ ฝ่ายวิศวกรรม │      │  ฝ่ายสนับสนุน │
     │   14 คน    │      │   6 คน    │      │    7 คน    │
     └────┬─────┘      └──────────┘      └────────────┘
     ┌────┴────┬─────────┐
  แผนกติดตั้ง  แผนกซ่อมบำรุง
    9 คน        5 คน
```

- **สลับสองมุมมองได้** — ผังตามฝ่าย/แผนก และผังตามสายหัวหน้างาน (Reporting Line) เพราะสองอย่างนี้ไม่จำเป็นต้องตรงกัน
- กดที่กล่องแล้วเห็นรายชื่อคนในกล่องนั้น
- **ต้องเห็นความผิดปกติจากผัง** — คนที่ไม่มีหัวหน้างาน · คนที่หัวหน้างานพ้นสภาพแล้ว · หัวหน้างานที่มีลูกทีมเกินจำนวนที่ตั้งไว้ · **วงจรที่ A เป็นหัวหน้า B และ B เป็นหัวหน้า A**
- พิมพ์หรือบันทึกเป็นภาพได้
- ตั้งต้นแสดงเฉพาะคนที่ยังทำงานอยู่ · เลือกให้แสดงคนพ้นสภาพได้

> ผังนี้เป็น **ภาพสะท้อน** ของข้อมูลในโปรไฟล์ ไม่ใช่ที่แก้ข้อมูล
> ถ้าจะให้ลากย้ายคนในผังได้ ต้องเป็นการเปลี่ยนช่องหัวหน้างานในโปรไฟล์จริง ๆ พร้อม audit log **อย่าทำเป็นผังที่แก้ได้แต่ไม่บันทึก**

# ข้อมูลที่หน้าจอเหล่านี้เรียกร้อง

| กลุ่ม | ข้อมูล |
|---|---|
| **ฝ่าย** | ชื่อ · อยู่ใต้บริษัทใด · สถานะใช้งาน/ปิด · ลำดับการแสดง |
| **แผนก** | ชื่อ · อยู่ใต้ฝ่ายใด · สถานะใช้งาน/ปิด · ลำดับการแสดง |
| **ตำแหน่ง** | ชื่อ · ระดับ · สถานะใช้งาน/ปิด · **ไม่ผูกกับสิทธิ์** |
| **การผูกคนเข้าโครงสร้าง** | คนหนึ่งมีหนึ่งแผนก หนึ่งตำแหน่ง หนึ่งหัวหน้างาน |
| **การล้างข้อมูล** | ค่าเดิมที่เป็นข้อความอิสระ ต้องเก็บไว้คู่กับค่าใหม่ที่คนกา จนกว่าจะยืนยันว่าเสร็จ |

**ช่องว่างที่จะเห็นทันทีเมื่อสร้างหน้าจอ**

1. **บริษัทมีกี่ฝ่าย ชื่ออะไร** — โครงสร้างในตัวอย่างเป็นของสมมติทั้งหมด ยังไม่เคยมีใครยืนยันของจริง
2. **คนหนึ่งอยู่ได้หลายแผนกไหม** — ช่างที่ทำทั้งติดตั้งและซ่อมบำรุงมีจริงหรือไม่ ถ้ามี โครงสร้างต้องรองรับ
3. **ระดับตำแหน่งมีกี่ระดับ** — ตัวอย่างสมมติไว้สี่ ของจริงยังไม่รู้
4. **ฝ่ายมีหัวหน้าฝ่ายไหม** — ตอนนี้ระบบรู้แค่หัวหน้างานรายคน ไม่รู้ว่าใครคุมฝ่าย ถ้าต้องรู้ ต้องเพิ่มช่อง
5. **13 คนที่กรอกว่า Project Manager** เป็นตำแหน่งจริงหรือแค่กรอกมั่ว — กระทบทั้งการล้างข้อมูลและผัง
