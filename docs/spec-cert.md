# ข้อกำหนดหน้าจอ — 9. Certificate & Employee Document

จัดทำ 8 ก.ย. 2569 · สถานะ: **พร้อมให้สร้างหน้าจอในต้นแบบ**

---

## อ่านก่อน

**ไฟล์นี้เป็นข้อกำหนด _หน้าตา_** — สร้างหน้าจอก่อน แล้วใช้หน้าจอตรวจว่าข้อมูลอะไรยังคิดไม่ถึง
ข้อมูลทุกตัวในตัวอย่างเป็นของสมมติ ห้ามใส่ชื่อพนักงานจริง

**ใบสั่งงานเดิมของเมนูนี้หายไป** ข้อตกลงที่เหลืออยู่ทั้งหมดถูกรวบมาไว้ในไฟล์นี้แล้ว

---

## สภาพจริงที่ต้องแก้ (ตรวจระบบเมื่อ 28 ส.ค. 2569)

ทั้งระบบมีใบเซอร์อยู่ **2 รายการ** ทั้งคู่เป็นของคนเดียวกัน และสองบรรทัดนั้นเปิดปัญหาไว้หมดแล้ว

- ชื่อใบมีเครื่องหมาย `"` ติดท้าย และ**เอารอบต่ออายุไปฝังในชื่อ** — `ใบ 4 ผู้ (ต่ออายุทุก 2 ปี)"`
- มีแต่ปุ่มลบ **ไม่มีแก้ไข ไม่มีต่ออายุ**
- รายการไม่แสดงสถาบันและวันที่ออกที่กรอกไปแล้ว
- ไม่มีอะไรทวงไฟล์แนบ — ทั้งสองรายการไม่มีไฟล์
- ใบหมดอายุแล้ว **ไม่มีใครถูกเตือน และยังจัดคนลงไซต์ได้ตามปกติ**
- Dashboard เอาใบเซอร์ไปปนกับการสอบเทียบเครื่องมือของอีกโมดูล

## กติกาที่ต้องยึด

| เรื่อง | ข้อสรุป |
|---|---|
| **ติดตาม 21 ชนิด** | ลิสต์จริงของบริษัท 14 + แนะนำเพิ่ม 7 · **ตั้งค่าได้ ห้าม hardcode** |
| **รอบต่ออายุอยู่ที่ชนิดใบ ไม่ใช่ในชื่อ** | ชื่อคือชื่อ รอบต่ออายุคือฟิลด์ |
| **ใบหมดอายุ → เตือนแรง แต่ผ่านได้** | ถ้ามีเหตุผล ต้องระบุเหตุผล + audit log · **ตั้งระดับการกันได้รายชนิดใบ** |
| **ผลตรวจสุขภาพและประวัติอาชญากรรม** | เก็บได้เฉพาะ **ผ่าน / ไม่ผ่าน + วันที่ + วันครบกำหนดถัดไป** ตาม PDPA มาตรา 26 · **ห้ามเก็บผลตรวจละเอียด ห้ามแนบไฟล์ผลตรวจ** |
| **ใครเปิดดูเอกสารสุขภาพได้** | เจ้าตัว · หัวหน้างานผู้อนุมัติ · ฝ่ายบุคคล · **ทุกครั้งที่เปิดลง audit log** · ผู้บริหารและแอดมินไม่เปิด รายงานแสดงแค่ครบ/ไม่ครบ |
| **ไม่ลบ** | ใบที่หมดอายุแล้วเก็บไว้เป็นประวัติ ต่ออายุคือการเพิ่มฉบับใหม่ ไม่ใช่ทับของเก่า |

**ผู้รับการแจ้งเตือน** — เจ้าของใบ · หัวหน้างาน · ฝ่ายบุคคล · ผู้บริหาร **เลือกได้รายชนิดใบ**

# หน้าจอที่ต้องสร้าง

## C1 · ภาพรวมใบเซอร์  `หน้าหลักของเมนูนี้`

```
┌──────────────────────────────────────────────────────────────┐
│  ใบรับรองและเอกสารพนักงาน                                    │
├──────────────────────────────────────────────────────────────┤
│   ใช้ได้ 84      ใกล้หมด 11      หมดอายุ 6      ยังไม่มี 23  │
│                  (ภายใน 60 วัน)                 (ใบบังคับ)   │
├──────────────────────────────────────────────────────────────┤
│  ⚠ ต้องจัดการก่อน                                            │
│    ธนา ศรีสุข — อบรมที่สูง หมดอายุแล้ว 12 วัน  แต่ลงไซต์อยู่ →│
│    วิภา ตั้งมั่น — ตรวจสุขภาพที่สูง ครบกำหนดใน 9 วัน        →│
├──────────────────────────────────────────────────────────────┤
│  [ รายคน ]  [ รายชนิดใบ ]                    [ + เพิ่มใบ ]   │
└──────────────────────────────────────────────────────────────┘
```

- **การ์ด "ยังไม่มี" สำคัญที่สุดและมักถูกลืม** — ระบบต้องรู้ว่าใครยัง**ไม่เคยมี**ใบบังคับ ไม่ใช่รู้แค่ว่าใบที่มีอยู่หมดอายุหรือยัง
- แถบ "ต้องจัดการก่อน" แสดงเฉพาะกรณีที่มีคนเสี่ยงจริง คือ **ใบหมดอายุ + คนนั้นยังถูกจัดลงไซต์อยู่**
- **ห้ามเอาการสอบเทียบเครื่องมือมาปนในหน้านี้** คนละโมดูล

**สถานะที่ต้องทำด้วย** — ยังไม่มีใบเซอร์ในระบบเลย · ทุกใบใช้ได้หมดไม่มีอะไรต้องเตือน · ผู้ใช้ไม่มีสิทธิ์

## C2 · มุมมองรายคน

```
┌────────────────────────────────────────────────────────────────┐
│  สมชาย ใจดี  STF-011  ช่างเทคนิคติดตั้ง        [ + เพิ่มใบ ]   │
├────────────────────────────────────────────────────────────────┤
│  ชนิดใบ                    วันที่ออก   หมดอายุ    สถานะ  ไฟล์ │
│  อบรมที่สูง                14 มี.ค.68  14 มี.ค.70  ใช้ได้  ✓  │
│  4 ผู้                     27 ส.ค.67   27 ส.ค.69  หมดอายุ ✓  │
│  จป.เทคนิค                 02 พ.ค.68   —          ใช้ได้  ✗  │
│  ตรวจสุขภาพทำงานที่สูง      10 ม.ค.69   10 ม.ค.70  ใช้ได้  🔒 │
│  ─────────────────────────────────────────────────────────    │
│  ยังไม่มี  ·  ดับเพลิงขั้นต้น · ปฐมพยาบาลเบื้องต้น            │
└────────────────────────────────────────────────────────────────┘
```

- **ท่อนล่าง "ยังไม่มี"** ต้องอยู่ในหน้าเดียวกัน ไม่ใช่หน้าแยก — ให้เห็นครบว่าคนนี้ขาดอะไร
- คอลัมน์ไฟล์ `✓` มีไฟล์ `✗` ไม่มีไฟล์ `🔒` เป็นเอกสารอ่อนไหว เปิดได้เฉพาะบทบาทที่กำหนด
- ใบที่ไม่มีวันหมดอายุ ให้ขึ้นขีด ไม่ใช่ปล่อยว่าง
- ประวัติการต่ออายุ กดที่ชื่อใบแล้วเห็นทุกฉบับที่เคยมี เรียงจากใหม่ไปเก่า

## C3 · ฟอร์มเพิ่มและต่ออายุใบ

```
   เพิ่มใบรับรอง
   ─────────────────────────────────────────────
   พนักงาน          [ สมชาย ใจดี ▾ ]
   ชนิดใบ           [ อบรมที่สูง ▾ ]      ← ดรอปดาวน์เท่านั้น
                    ℹ ใบนี้ต่ออายุทุก 2 ปี · เป็นใบบังคับสำหรับงานหน้าไซต์
   ออกโดย/สถาบัน    [                    ]
   เลขที่ใบ         [                    ]
   วันที่ออก        [ 14 / 03 / 2568     ]
   วันหมดอายุ       [ 14 / 03 / 2570     ]  ☑ คำนวณจากรอบต่ออายุให้
   ไฟล์แนบ         [ เลือกไฟล์ ]  ⚠ ยังไม่แนบไฟล์
   หมายเหตุ         [                    ]
                                    [ ยกเลิก ]  [ บันทึก ]
```

- **ชนิดใบเป็นดรอปดาวน์เท่านั้น ห้ามพิมพ์เอง** — ที่มาของ `ใบ 4 ผู้ (ต่ออายุทุก 2 ปี)"` คือการพิมพ์เอง
- เลือกชนิดแล้วขึ้นข้อมูลกำกับทันทีว่ารอบต่ออายุเท่าไร บังคับหรือไม่
- วันหมดอายุ **คำนวณให้แต่แก้ทับได้** เพราะบางใบพิมพ์วันหมดอายุมาเอง ติ๊กออกแล้วกรอกเองได้
- ไม่แนบไฟล์ก็บันทึกได้ **แต่ต้องขึ้นเตือนค้างไว้** และไปโผล่ในรายการงานค้าง
- **ฟอร์มของใบสุขภาพและประวัติอาชญากรรมเป็นคนละฟอร์ม** ดู C4

**ต่ออายุ** ใช้ฟอร์มเดียวกัน แต่กรอกชนิดใบและพนักงานให้แล้ว และเขียนไว้ว่าฉบับเดิมจะถูกเก็บเป็นประวัติ ไม่ถูกทับ

## C4 · ฟอร์มเอกสารอ่อนไหว  `PDPA` `ห้ามทำเหมือน C3`

ใช้กับ ตรวจสุขภาพทำงานที่สูง · ตรวจประวัติอาชญากรรม · ตรวจ 5 โรคและสารเสพติด

```
   บันทึกผลตรวจ
   ─────────────────────────────────────────────
   🔒 เอกสารอ่อนไหวตาม PDPA มาตรา 26
      ระบบเก็บได้เฉพาะผลผ่าน/ไม่ผ่านและวันที่
      ห้ามแนบไฟล์ผลตรวจ ห้ามกรอกรายละเอียดผล

   พนักงาน          [ สมชาย ใจดี ▾ ]
   รายการตรวจ       [ ตรวจสุขภาพทำงานที่สูง ▾ ]
   ผล               ( ) ผ่าน   ( ) ไม่ผ่าน
   วันที่ตรวจ        [ 10 / 01 / 2569 ]
   ครบกำหนดถัดไป    [ 10 / 01 / 2570 ]
                                    [ ยกเลิก ]  [ บันทึก ]
```

- **ไม่มีช่องแนบไฟล์ ไม่มีช่องรายละเอียดผล ไม่มีช่องหมายเหตุ** ในฟอร์มนี้
- ข้อความ PDPA อยู่ในหน้าตั้งค่า แก้ได้
- ทุกครั้งที่**เปิดดู**รายการในกลุ่มนี้ ลง audit log ไม่ใช่แค่ตอนแก้
- ในรายงานและ Dashboard รายการกลุ่มนี้แสดงได้แค่ **ครบ / ไม่ครบ** ห้ามแสดงคำว่าผ่านหรือไม่ผ่านให้บทบาทที่ไม่มีสิทธิ์

## C5 · ตั้งค่าชนิดใบรับรอง

```
┌─────────────────────────────────────────────────────────────────────┐
│  ชนิดใบรับรอง                                    [ + เพิ่มชนิด ]    │
├─────────────────────────────────────────────────────────────────────┤
│  ชื่อ                    รอบต่ออายุ  บังคับกับ      กัน      แจ้ง   │
│  อบรมที่สูง               2 ปี       งานหน้าไซต์   เตือนแรง  ⋮     │
│  จป.เทคนิค                ไม่หมดอายุ  หัวหน้าชุด    เตือน    ⋮     │
│  4 ผู้                    2 ปี       งานหน้าไซต์   เตือนแรง  ⋮     │
│  ตรวจสุขภาพทำงานที่สูง 🔒  1 ปี       งานหน้าไซต์   เตือนแรง  ⋮     │
│  ใบอนุญาตขับรถ            5 ปี       คนขับรถ      เตือน     ⋮     │
└─────────────────────────────────────────────────────────────────────┘
```

**ฟิลด์ของแต่ละชนิด**

| ฟิลด์ | ค่าที่เลือกได้ |
|---|---|
| ชื่อ | ข้อความ |
| รอบต่ออายุ | จำนวนปี/เดือน หรือ "ไม่หมดอายุ" |
| บังคับกับใคร | ทุกคน · ตามประเภทงาน · ตามตำแหน่ง · ไม่บังคับ |
| **ระดับการกัน** | ไม่กัน · เตือนเฉย ๆ · **เตือนแรงแต่ผ่านได้ถ้าระบุเหตุผล** |
| ผู้รับการแจ้งเตือน | ติ๊กได้หลายคน — เจ้าของใบ · หัวหน้างาน · ฝ่ายบุคคล · ผู้บริหาร |
| เตือนล่วงหน้ากี่วัน | ตัวเลข ตั้งได้รายชนิด |
| ธงอ่อนไหว PDPA 🔒 | ติ๊ก — ติ๊กแล้วบังคับใช้ฟอร์ม C4 และซ่อนช่องแนบไฟล์ |

**ข้อมูลตั้งต้น 21 ชนิด**

*ลิสต์จริงของบริษัท 14* — พื้นฐานการบริหารโครงการ · การปฐมพยาบาลเบื้องต้น · ความปลอดภัยในพื้นที่อับอากาศ · Forklift · จป.เทคนิค · การติดตั้งนั่งร้าน · จป.หัวหน้างาน · 4 ผู้ · อบรมที่สูง · อบรม 6 ชม. · อบรม 3 ชม. · ตรวจสุขภาพทำงานที่สูง 🔒 · ตรวจประวัติอาชญากรรม 🔒 · ตรวจ 5 โรคและสารเสพติด 🔒

*แนะนำเพิ่ม 7* — หนังสือรับรองช่างไฟฟ้าภายในอาคาร · จป.บริหาร · ความปลอดภัยไฟฟ้า 3 ชม. · ดับเพลิงขั้นต้น · ใบ กว. ไฟฟ้ากำลัง · ขึ้นทะเบียนผู้ติดตั้งกับการไฟฟ้า · ใบอนุญาตขับรถ

## C6 · หน้าจอตอนใบหมดอายุแล้วยังจะจัดคนลงไซต์

จุดที่เมนูนี้มีค่าจริง ๆ อยู่ตรงนี้ที่เดียว **ถ้าไม่มีหน้าจอนี้ ที่ทำมาทั้งหมดเป็นแค่ที่เก็บไฟล์**

```
   ⚠ ธนา ศรีสุข มีใบบังคับที่หมดอายุแล้ว
   ─────────────────────────────────────────────
   อบรมที่สูง        หมดอายุ 27 ส.ค. 2569 (12 วันที่แล้ว)

   ระดับการกันของใบนี้: เตือนแรง — ผ่านได้ถ้าระบุเหตุผล

   เหตุผลที่ยังให้ลงไซต์  [                              ]
                          ต้องกรอก · บันทึกชื่อผู้อนุมัติและเวลา

                            [ ยกเลิก ]  [ ยืนยันและบันทึก ]
```

- ขึ้นตอน**กำลังจะจัดคนลงไซต์** ไม่ใช่ขึ้นย้อนหลัง
- ระดับ "ไม่กัน" ไม่ต้องขึ้นอะไรเลย · ระดับ "เตือนเฉย ๆ" ขึ้นแล้วกดผ่านได้โดยไม่ต้องกรอก
- ทุกครั้งที่ผ่านด้วยเหตุผล ลง audit log และไปโผล่ในรายงานให้ผู้บริหารเห็นว่าเดือนนี้ยกเว้นไปกี่ครั้ง

> **ข้อจำกัดที่ต้องรู้** — ในเฟสนี้ไม่มีระบบมอบหมายกำลังคนล่วงหน้า (S22 ไม่อยู่ในเฟสนี้)
> จุดที่หน้าจอนี้เด้งได้จริงจึงมีแค่ **ตอนเช็คอินเข้าไซต์** ไม่ใช่ตอนวางแผน · เขียนไว้ให้ชัดในต้นแบบว่าเป็นข้อจำกัดชั่วคราว

| **สถานะที่คำนวณ** | ใช้ได้ · ใกล้หมด · หมดอายุ · **ยังไม่เคยมี** ← ตัวสุดท้ายไม่ได้มาจากตารางใบ ต้องเทียบกับรายการใบบังคับ |
| **การยกเว้น** | ใครยกเว้นให้ใคร ใบไหน เมื่อไร ด้วยเหตุผลอะไร |
| **การเปิดดู** | ใครเปิดดูเอกสารอ่อนไหวของใคร เมื่อไร |

**ช่องว่างที่จะเห็นทันทีเมื่อสร้างหน้าจอ**

1. **"บังคับกับใคร" อ้างอะไร** — ถ้าอ้างประเภทงาน ก็ผูกกับ S19 · ถ้าอ้างตำแหน่ง ก็ผูกกับ `spec-org.md` ซึ่งตำแหน่ง**ว่างทั้ง 31 คน** แปลว่าฟีเจอร์กันคนลงไซต์ยังทำงานไม่ได้จนกว่าจะล้างข้อมูลตำแหน่งเสร็จ
2. **"อบรม 6 ชม." และ "อบรม 3 ชม." คือหลักสูตรอะไรแน่** — เดาไว้ว่า 6 ชม. เป็นความปลอดภัยฯ สำหรับลูกจ้างเข้าใหม่ และ 3 ชม. เป็น site induction ของโรงงานลูกค้า **ยังไม่ยืนยัน** ถ้าเป็น site induction จริง มันผูกกับไซต์ ไม่ใช่ผูกกับคน ซึ่งเปลี่ยนโครงสร้างข้อมูล
3. **วันหมดอายุมาจากไหน** — คำนวณจากวันที่ออก หรือกรอกตามที่พิมพ์บนใบ · ฟอร์มออกแบบไว้ให้ทำได้ทั้งสองแบบ แต่ต้องเลือกว่าอันไหนเป็นค่าตั้งต้น
4. **ต้องบังคับว่าออกโดยหน่วยฝึกที่ขึ้นทะเบียนกับกรมสวัสดิการฯ หรือไม่** — ถ้าต้อง ก็ต้องมีทะเบียนหน่วยฝึกอีกตาราง
5. **รอบตรวจสุขภาพใช้ 1 ปีเท่ากันทุกกลุ่มงาน หรือแยกตามความเสี่ยง**
