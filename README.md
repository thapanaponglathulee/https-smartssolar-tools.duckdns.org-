# โมดูลบุคคล — Solar Tools Center

ระบบภายในของ **บริษัท สมาร์ท เอ็น คอนซัลแทนท์ จำกัด** · `smartssolar-tools.duckdns.org`

โฟลเดอร์นี้เก็บสามอย่างที่ทำงานคู่กัน — **ข้อกำหนด** · **ต้นแบบที่กดได้** · **บริบทสำหรับ Claude Code**

```
CLAUDE.md              บริบทโปรเจกต์ · อ่านก่อนเสมอ ทุกแชทใหม่
dev-handoff/           ชุดส่งงาน — ข้อกำหนดทั้งหมด (ห้ามแก้ เป็นสำเนาจากโฟลเดอร์ HR)
prototype/             โค้ดต้นแบบที่ Claude Code สร้าง
```

---

## วิธีทำงานสองขั้น

บริษัท**ไม่มีซอร์สโค้ดของระบบจริง**และจะไม่ได้มา งานจึงแบ่งเป็น

1. **ขั้นพิสูจน์ข้อกำหนด** — สร้างต้นแบบจากข้อกำหนดใน `dev-handoff/docs/` ให้คนของบริษัทกดเล่นจริง จนมั่นใจว่าข้อกำหนดถูก
2. **ขั้นส่งมอบ** — ส่ง *ข้อกำหนดที่พิสูจน์แล้ว* + *ต้นแบบที่กดได้* ให้ผู้พัฒนาระบบจริงไปทำ

> ต้นแบบไม่ใช่ระบบจริงและไม่ต้องพยายามเป็น — หน้าที่ของมันคือ**ทำให้ข้อกำหนดผิดถูกเห็นได้ด้วยตา**

---

## เปิดต้นแบบ

```bash
cd prototype
npx http-server -p 8080 .     # แล้วเปิด http://localhost:8080
```

เปิด `prototype/index.html` จากเครื่องตรง ๆ ก็ได้ · ไม่ต้องติดตั้งอะไร ไม่มี dependency

**ส่งให้ทีมทดสอบ** — `cd prototype && node tools/build-single-file.js`
ได้ `prototype/dist/mockup-uat-standalone.html` ไฟล์เดียวจบ แนบอีเมลหรือ LINE ได้เลย
